# Ronda 5S DEM

App de lancamento rapido de nao conformidades do programa 5S.

**Abrir o app:** https://drill23.github.io/ronda5s-dem/

- Funciona offline (service worker proprio, cache isolado `ronda5s-dem-`)
- Instalavel na tela de inicio do iPhone (icone proprio)
- Busca inteligente com lexico de sinonimos e frequencia real das NCs
- Exporta o checklist Excel no mesmo modelo, TXT, copia e folha manuscrita
- Icones hospedados no issue #1
